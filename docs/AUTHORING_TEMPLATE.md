# Формат авторского документа

Этот формат придуман для того, чтобы приложение не угадывало. Сегодня конвертер
разбирает редакционные документы MAXIMUM и вынужден догадываться: скобка или
точка у пункта, кириллическая «В» или латинская «B», где кончается условие и
начинаются варианты, что означает ключ из одних цифр. Каждая догадка когда-то
ошибается, и ученик видит нечитаемое задание.

В авторском документе догадываться нечего. Тип задания назван словом, пункты и
варианты лежат под своими заголовками, ответ стоит в своём поле. Читатель этого
формата не эвристический: он либо понимает документ целиком, либо называет
задание и поле, которые нужно поправить.

## Один документ — один набор заданий

Документ начинается с шапки. Каждое поле шапки занимает один абзац.

```text
Предмет: Биология
Экзамен: ЕГЭ
Класс: 11
Сезон: 21-22
Тема: Цитология
```

`Предмет` — одно из: Английский язык, Биология, Информатика, История,
Литература, Математика, Обществознание, Русский язык, Физика, Химия.
`Экзамен` — ЕГЭ или ОГЭ. `Класс` — число. `Сезон` — учебный год двумя парами
цифр. `Тема` — название темы, попадает в результат ученика.

## Задание

Задание открывается абзацем `Задание N`, где N — номер по порядку. Дальше идут
поля. Порядок полей свободный, но каждое поле встречается один раз.

```text
Задание 1
Тип: один ответ
Условие:
В какой фазе митоза хромосомы выстраиваются по экватору клетки?
Варианты:
1) Профаза
2) Метафаза
3) Анафаза
4) Телофаза
Ответ: 2
Решение:
В метафазе хромосомы выстраиваются в экваториальной плоскости.
```

`Тип` — одно из пяти значений, и оно решает всё остальное:

| Тип | Что заполняется | Что в поле «Ответ» |
|---|---|---|
| один ответ | Варианты | номер одного варианта |
| несколько ответов | Варианты | номера через запятую |
| соответствие | Пункты и Варианты | по одной цифре на каждый пункт, подряд |
| последовательность | Варианты, Пункты по желанию | цифры подряд, в нужном порядке |
| число | ничего | само число |
| короткий ответ | ничего | слово или короткая фраза |

Разница между «несколько ответов» и «последовательностью» в том, важен ли
порядок. Если ученик выбирает три верных утверждения из шести, порядок не важен,
это «несколько ответов». Если он заполняет пустые ячейки таблицы или расставляет
события по времени, порядок и есть ответ, это «последовательность». В
последовательности цифра может повторяться, в «нескольких ответах» нет.

`Условие` обязательно всегда. Абзацы после заголовка `Условие:` и до следующего
заголовка составляют текст задания. Таблица Word, поставленная внутри условия,
остаётся частью условия и показывается таблицей.

`Решение` необязательно. Если оно есть, ученик увидит его в разборе ошибок.

`Тема` в задании необязательна. Без неё берётся тема из шапки.

## Соответствие

У соответствия два списка. Пункты нумеруются буквами, варианты цифрами.

```text
Задание 3
Тип: соответствие
Условие:
Установите соответствие между событиями и годами.
Пункты:
А) Восстание декабристов на Сенатской площади
Б) Издание манифеста о вольности дворянской
В) Поход князя Игоря против половцев
Варианты:
1) 1185
2) 1825
3) 1613
4) 1762
Ответ: 241
```

Ответ читается по порядку пунктов: А соответствует 2, Б соответствует 4,
В соответствует 1. Вариантов может быть больше, чем пунктов, лишние допустимы.

## Несколько принимаемых формулировок

У короткого ответа можно перечислить несколько допустимых написаний, каждое с
новой строки.

```text
Тип: короткий ответ
Ответ:
цитогенетический
кариотипирование
цитологический
```

Регистр, буква «ё», лишние пробелы, кавычки и точка в конце не влияют на
проверку. Дефис влияет: в задании на слитное и раздельное написание он и есть
ответ.

## Рисунки

Рисунок вставляется в условие как обычная картинка Word. Приложение уменьшает
её до 900 точек по большей стороне. Если условие ссылается на рисунок, а
рисунка нет, задание не будет принято.

## Чего в документе быть не должно

Не пишите, куда записать ответ. Строки вида «в ответ запишите
последовательность цифр» описывают бумажный бланк, которого в приложении нет.
Ответ собирает интерфейс: у выбора это кнопки, у соответствия это списки, у
числа и короткого ответа это поле ввода с подсказкой о формате.

Не нумеруйте варианты вручную внутри текста условия. Для этого есть поле
`Варианты`.

## Проверка документа

Перед передачей документ проверяется командой. Она называет задание и поле, в
котором ошибка, и ничего не меняет.

```text
python scripts/check_authoring_document.py <файл.docx>
```

Ошибка выглядит так:

```text
Задание 12, поле «Ответ»: у задания типа «соответствие» ответ должен состоять
из 3 цифр по числу пунктов, получено 4.
```

## Как переносится существующее содержимое

Готовые редакционные документы переводятся в этот формат командой. Она
заполняет всё, что удалось прочитать однозначно, и оставляет пустыми поля, о
которых пришлось бы догадываться, помечая их словом `ТРЕБУЕТ ПРОВЕРКИ`.

```text
python scripts/convert_to_authoring_template.py <исходный.docx> <результат.docx>
```

Методист открывает результат, заполняет помеченные поля и запускает проверку.
Догадки остаются человеку, а не программе.
