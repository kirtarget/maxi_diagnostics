**ОГЭ**: полные официальные таблицы получены напрямую из PDF Рособрнадзора (см. ниже), извлечены и проверены построчно — высокая уверенность.

Использована таблица агрегатора **ctege.info**, который прямо указывает: «Рособрнадзор выложил 7.05.2026 шкалу перевода баллов для всех предметов ЕГЭ 2026 г. Шкала такая же, как и в 2025 году», ссылаясь на fipi.ru как источник. Максимальные первичные баллы по каждому предмету перепроверены по независимой странице (школьный сайт, republishing ctege.info) — совпадают.

**Обнаруженные дефекты источника ctege.info** (важно для доверия к точным значениям):
- **Физика**: в извлечённой таблице отсутствует/повреждено значение тестового балла для первичного балла 17 (значение "43" явно ошибочно — повторяет более раннее значение, нарушая монотонность; должно быть между 51 и 54).
- **Литература**: отсутствует значение для первичного балла 14; вокруг первичных баллов 24-26 в исходной HTML-таблице порядок строк был нарушен (артефакт вёрстки/парсинга), восстановлен по возрастающей последовательности, но не подтверждён напрямую.
- **Иностранные языки (английский и др.)**: отсутствует/искажено значение для первичного балла 29 (в источнике вместо "29" стоит "39", что нарушает последовательность).

Эти три предмета помечены в JSON как `"confidence": "secondary-with-gaps"`, соответствующие ячейки таблицы — `null`. Перед использованием в проде рекомендуется свериться с оригинальным решением Рособрнадзора (обычно публикуется как приложение к письмам 04-*/КИД на obrnadzor.gov.ru) или с методическими материалами ФИПИ (`doc.fipi.ru/ege/...`).

- Русский язык: 24 балла — минимум для получения аттестата (отдельно от вузовского минимума 36).

- Информатика сдаётся в компьютеризированной форме (КЕГЭ), максимум первичных баллов — 29 (в отличие от исторических 27-28 в бумажной форме).

Полные массивы значений — в `score-scales-2026.json`, поле `ege.<slug>.table` (индекс = первичный балл, значение = тестовый балл; `null` — не подтверждено).

## Ограничения этого исследования

- Не найден и не запрошен напрямую PDF решений Рособрнадзора 04-1/КИД, 04-2/КИД, 04-3/КИД, 04-6/КИД (март-апрель 2026) — доступ к `obrnadzor.gov.ru` и `fipi.ru` через `WebFetch` был заблокирован средой ("Unable to verify if domain is safe to fetch"); прямая ссылка на итоговый PDF со сводной шкалой по всем предметам ЕГЭ через поиск не обнаружена.
- Для физики, литературы и иностранных языков ЕГЭ есть по одному пропущенному/сомнительному значению в таблице (см. выше) — отмечено `null` в JSON, требует ручной сверки перед использованием в продакшене.
- География не входила в список нужных 10 предметов и не включена в вывод, хотя данные по ней также были получены (доступны в сырых файлах при необходимости).
