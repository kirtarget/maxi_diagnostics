# Конкретные темы заданий и понятный результат диагностики

Дата: 2026-08-12

## Цель

Сделать результат диагностики полезным для ученика: показывать конкретный
проверенный навык вместо общего названия предмета и не выдавать слабый сигнал за
уверенный вывод.

## Контент

- Каждое из 178 заданий получает одну конкретную тему в поле `topic`.
- Общие темы-предметы (`Русский язык`, `Математика`, `Биология` и аналогичные)
  запрещены валидатором каталога.
- Темы формулируются как школьные навыки или разделы программы: например,
  `Орфоэпия`, `Степень окисления`, `Кратчайший путь в графе`.

## Результат Mini App

- Если по теме есть не менее двух заданий и доля правильных ответов ниже 70%, она
  выводится как `Тема для повторения`.
- Если тема встречается только в одном задании и ответ неверен, выводится
  нейтральное `Стоит повторить`, без заявления о системном пробеле.
- Технический блок `Границы проверки` переименовывается в `Что вошло в
  диагностику` и показывается только при частичной диагностике.

## PDF

- В колонке `Правильный ответ` всегда выводится эталон из неизменяемого снимка
  завершённой попытки.
- `Не отвечено` допускается только в колонке `Ваш ответ`.
- Для каждого задания PDF выводит короткий текстовый разбор только на основе
  подтверждённого материала учебника MAXIMUM. URL хранится лишь как внутренний
  источник и ученику не показывается. При отсутствии материала выводится
  честная пометка, что разбор ещё не добавлен.

## Проверки

- Тесты покрывают запрет общих тем, нейтральную формулировку для единственного
  задания и раздельное отображение ответа ученика и эталона в PDF.
- После разметки выполняются валидация школы, релевантные Python/Mini App тесты и
  production-сборка.
