# Карта учебного архива SharePoint

Используйте эту карту перед поиском учебных материалов. Она описывает архив
MAXIMUM, а не текущий runtime-каталог приложения.

## Точка входа

Архив: [Разработка 2024-2025 / Контент приложения](https://maximumkz.sharepoint.com/sites/razrabotka2025/Shared%20Documents/Forms/AllItems.aspx?id=%2Fsites%2Frazrabotka2025%2FShared%20Documents%2F%D0%9A%D0%9E%D0%9D%D0%A2%D0%95%D0%9D%D0%A2%20%D0%9B%D0%9A%2F%D0%9A%D0%BE%D0%BD%D1%82%D0%B5%D0%BD%D1%82%20%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F).

Для доступа используйте уже авторизованную вкладку SharePoint. Не загружайте
архив целиком. Сначала соберите метаданные папки, затем выборочно открывайте
документы, которые стали кандидатами на импорт.

## Типовой путь ЕГЭ

`<код>/11 класс/` обычно содержит `Варианты`, `Задания`, `Теория` и
`Тренажёры`. У физики, химии и обществознания тематический банк расположен
в `ОДЗ`; у математики, биологии, информатики, литературы и русского языка —
в `Задания`.

| Предмет | Рабочая тематическая ветка |
|---|---|
| Математика | `МА/11 класс/Задания` |
| Биология | `БИО/11 класс/Задания` |
| Информатика | `ИНФ/11 класс/Задания` |
| Литература | `ЛИТ/11 класс/Задания` |
| Русский язык | `РЯ/11 класс/Задания` |
| Физика | `ФИЗ/11 класс/ОДЗ` |
| Химия | `ХИМ/11 класс/ОДЗ` |
| Обществознание | `ОБЩ/11 класс/ОДЗ` |
| Английский язык | `АЯ/11 класс/Задания` |

Математика, биология, информатика, литература и русский язык организованы по
учебным темам. Физика, химия и обществознание организованы по разделам предмета.
Папки `Исходники` внутри темы требуют отдельного обхода и не входят в цифры
первого уровня.

## Типовой путь ОГЭ

У большинства предметов рабочая ветка находится в `<код>/9 класс/`. История
использует исключение `ИСТ/9 класс (ОГЭ)/ОДЗ`. Для ОГЭ сначала смотрите
`Задания` или `ОДЗ`, затем `Варианты` и `Тренажёры`. Полная таблица папок
зафиксирована в [PHASE_1.md](PHASE_1.md).

Для скриптов и агентов используйте
[`phase-1-summary.json`](phase-1-summary.json). В нём хранится тот же срез с
явными ограничениями подсчёта.

## Что уже проверено

Количественный срез и правила следующей фазы находятся в
[PHASE_1.md](PHASE_1.md). На 6 сентября 2026 года подтверждено минимум 539
DOCX и 4 485 заданий по десяти предметам ЕГЭ. Это не полный объём архива.

Фаза 2 описана в [PHASE_2.md](PHASE_2.md). Инструмент
`scripts/sharepoint_inventory_manifest.py` строит manifest с хэшами, дублями и
итогом конвертации по локальной выборке `.tmp/sharepoint-sample/`, которая
повторяет структуру папок SharePoint. Результаты лежат в
`phase-2-manifest.json` и `phase-2-dedup.md`. Решения по именованию, ключам и составу
пакетов и план импорта лежат в `phase-2-import-plan.json` и в разделе
«Решения» PHASE_2.md. Тематическая выборка уже
загружена, это 56 DOCX по пяти предметам плюс 20 DOCX папки `Диагностики`.
Блокера доступа больше нет, файлы получены через REST API SharePoint из
авторизованного браузера владельца.

## Копии в авторском формате

Все DOCX локальной выборки переведены в единый авторский формат
(`docs/AUTHORING_TEMPLATE.md`) и лежат в `authoring/sharepoint-authoring/`.
Отчёт `authoring/sharepoint-authoring/report.md` перечисляет типы заданий по
файлам и каждое поле, которое методист заполняет вручную. Пересобрать копии:
`python scripts/convert_to_authoring_template.py .tmp/sharepoint-sample authoring/sharepoint-authoring`.

## Правила работы с источниками

1. Не копируйте материалы в `school/` напрямую.
2. Фиксируйте путь, имя файла, тему и число заданий в manifest до импорта.
3. Перед загрузкой документа проверяйте, есть ли ключи, объяснения и ресурсы.
4. Импортируйте только через `scripts/import_sharepoint_diagnostics.py` или его
   расширение с dry-run. Каждый runtime-вопрос должен получить идентификатор `sp-…`.
   Импортёр заменяет все `sp-` вопросы содержимым переданной папки, поэтому
   в папке источников должны лежать и 20 DOCX `Диагностики`, и новые файлы.
5. После изменения каталога запускайте `scripts/validate_school.py` и
   `scripts/check_brand_isolation.py`.

## Границы данных

Текущий каталог приложения содержит только минимальную выборку из папки
`Диагностики`. Он не отражает полноту предметных папок. Не сообщайте 348 как
размер всего банка заданий.
