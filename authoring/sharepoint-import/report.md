# Импорт диагностик SharePoint

Сгенерировано `python scripts/import_sharepoint_diagnostics.py <docx-dir>` (2026-09-03).

Текст задания, вариантов и ключ взяты из редакционно утверждённых документов MAXIMUM без правок. Тема и первичный балл проставлены автоматически: они переносятся из `docs/FIPI_2026_CONTENT_MATRIX.md` только тогда, когда целевая диагностика уже утверждает ту же позицию КИМ для своего «Задание N». В остальных случаях тема равна «Задание N», балл равен 1, и строка помечена `topic_unmapped`. Все импортированные вопросы имеют `approval_status = draft` и требуют предметной редактуры.
